# AI 추론은 클라우드 API만 사용한다

음성 인식(STT), 언어 모델(LLM), 음성 합성(TTS)은 모두 클라우드 API로 처리하고, 로컬 모델은 쓰지 않는다.
이 결정으로 GPU 추론 노드와 로컬 모델 관련 스파이크가 범위에서 빠진다. 대신 인터넷이 끊기면 음성
기능 전체가 멈춘다.

## 결정

- STT, LLM, TTS는 클라우드 공급자의 API로만 처리한다. 서버나 데스크톱에서 모델을 돌리지 않는다.
- 웨이크워드 감지와 VAD(발화 구간 판정)는 허브에서 계속 실행한다. 이 둘은 상시 오디오를 외부로 보내지
  않기 위한 장치이고, 클라우드로 대체할 수 있는 대상이 아니다.
- 어떤 공급자를 쓸지, 단계별 API를 이어 붙일지(STT → LLM → TTS) 아니면 실시간 음성 API 하나를 쓸지는
  이 결정의 범위가 아니다. 스파이크 S2에서 클라우드 선택지끼리 비교해 별도 ADR로 정한다.

## 배경과 제약

이전 설계는 "로컬 LLM이 두뇌"를 정체성으로 내세웠다가 v3.3에서 클라우드 우선으로 돌아섰고, 그 결과 문서
안에 두 제품이 공존했다([검토 C1](../review/2026-11-13-legacy-design-adversarial-review.md)). GPU 데스크톱을
상시 서버로 쓰는 계획도 로컬 추론을 전제로 했다(검토 C2).

프로젝트 소유자는 로컬 모델의 성능이 이 프로젝트의 한국어 음성 경험에 부족하다고 판단해 로컬 모델 사용을
기각했다. 이 판단은 소유자의 사용 경험에 근거한 것이며, 이 프로젝트에서 로컬과 클라우드를 같은 조건으로
비교 측정한 결과는 없다.

## 근거와 대안

검토한 대안은 세 가지였다.

| 대안 | 내용 | 기각 이유 |
|---|---|---|
| 로컬 우선 | 로컬 STT·LLM·TTS를 기본으로, 클라우드는 폴백 | 소유자가 로컬 모델 품질을 받아들일 수 없다고 판단 |
| 혼합 | 로컬 STT·TTS + 클라우드 LLM (이전 설계 v3.3 구성) | 위와 같은 판단. 로컬 TTS 1순위였던 Supertonic 3는 2026-09-09 개발이 종료됐다 |
| 오프라인 대비용 로컬 폴백 | 평소에는 클라우드, 인터넷 단절 시에만 로컬 | 쓰는 빈도가 낮은 경로를 유지하는 비용이 크다. 단절 시에는 터치 제어와 알람으로 버틴다 |

클라우드만 쓰면 얻는 것은 다음과 같다. 상시 서버에 GPU가 필요 없으므로 저전력 머신 한 대로 충분하다.
모델 배포, VRAM 예산, 드라이버 호환 같은 운영 작업이 사라진다. 스파이크 S2가 클라우드 선택지끼리의
비교로 좁혀지고, S4(서버 하드웨어)에서 GPU 필요 여부를 따질 이유가 없어진다.

## 영향

- **인터넷 단절:** 호출어는 감지되지만 음성 명령은 처리할 수 없다. 허브는 "인터넷 연결이 없어 음성
  명령을 처리할 수 없어요"를 표시한다. 터치 대시보드(로컬 통합 기기), 알람, Home Assistant 자동화는
  계속 동작한다. 오프라인 음성 제어는 목표에서 뺀다.
- **프라이버시:** 호출어 이후의 발화 오디오와 그 전사문, 기기 목록, 대화 맥락이 클라우드 공급자에게
  전달된다. 이전 설계의 "로컬 우선이라 프라이버시가 구조적으로 우위"라는 주장은 철회한다. 호출어
  이전의 상시 오디오는 허브 밖으로 나가지 않는다. 공급자를 고를 때 데이터 보존·학습 사용 정책을 비교
  항목에 넣는다. 무료 티어는 입력이 학습에 쓰일 수 있다.
- **비용:** 사용량에 비례하는 API 비용이 생긴다. 오탐으로 열린 세션도 과금되므로, 웨이크워드 오탐률(S1)이
  비용에도 영향을 준다. 월 비용은 S2에서 1회당 비용을 실측한 뒤 추정한다.
- **공급자 의존:** 모델 종료, 가격 변경, API 변경을 따라가야 한다. 공급자는 하나를 골라 그 하나만 구현하고,
  교체가 실제로 필요해질 때 인터페이스를 추출한다.
- **문서 반영:** [전체 시스템](../design/0001-system-architecture.md)과
  [서버](../design/0002-server-architecture.md) 설계안에서 GPU 추론 노드를 제거하고, 장애 시 동작을
  위 내용으로 바꾼다. [검토 보고서](../review/2026-11-13-legacy-design-adversarial-review.md)의 S2·S4·S8에
  남아 있는 로컬 선택지는 이 결정으로 비교 대상에서 빠진다.
