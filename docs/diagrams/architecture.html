Cozy Buddy 아키텍처

재설계 초안(draft) 기준의 목표 구조. AI 추론은 클라우드 API만 사용하고(ADR 0001), 기기와 자동화는 Home Assistant에 맡긴다. 스파이크로 정할 부분은 상자 안에 표시했다.

전체 시스템

허브와 휴대폰 앱은 Cozy Server만 상대한다. 서버는 Home Assistant를 MCP와 WebSocket API 두 지점으로만 쓰고, 음성 처리는 클라우드 AI에 맡긴다. 알람은 허브가 직접 울린다.

상세: 0001 전체 시스템 아키텍처

서버

FastAPI 단일 프로세스. 도메인별 패키지로 나누고, 기기·방·자동화는 저장하지 않는다. 짧은 명령은 결정론 매처가 템플릿으로 즉시 처리하고, 나머지만 LLM 툴 루프로 보낸다.

허브 (태블릿)

평소에는 앰비언트 시계를 띄워 두는 HOME 앱. 웨이크워드와 VAD는 허브에서 실행해 호출어 이전의 오디오를 밖으로 보내지 않는다. Android 17 오디오 제한 때문에 서비스는 반드시 보이는 Activity에서 시작한다.

휴대폰 앱

집 밖에서 쓰는 얇은 클라이언트. 판단은 모두 서버가 하고, 서버는 Tailscale로만 닿는다. 허브 알람은 서버를 거쳐 허브에 전달되며, 허브가 꺼져 있으면 전달 대기로 표시한다.
