# 개발 계획

첫 목표는 [전체 시스템 설계안](../design/0001-system-architecture.md)의 완료 기준인 "태블릿 1대 음성 제어 루프 +
서버 없이 울리는 알람"이다. 스파이크 결과가 필요 없는 기반 작업(레포 정리, 프로토콜, 서버·허브 골격, 로컬
알람)을 먼저 진행하고, 하드웨어·API 키·기기가 필요한 스파이크는 소유자의 준비가 끝나는 대로 붙인다. 지금
막혀 있는 것은 모두 소유자 쪽 준비물이다.

## 기준 시점과 일정

기준일은 2026-11-13이다. 날짜 대신 단계로 관리한다. 각 단계는 앞 단계의 완료 조건을 만족해야 시작한다.

| 단계 | 내용 | 완료 조건 |
|---|---|---|
| 1. 기반 | 레포 정리, 프로토콜 v1, 서버 골격, 허브 골격과 앰비언트 화면, 허브 로컬 알람 | 서버와 허브가 `ClientHello`로 연결되고, 허브 알람이 서버 없이 울린다 |
| 2. 스파이크 | S1(웨이크워드), S2(음성 경로), S3(Home Assistant) 우선 | 각 스파이크의 실험 보고서와 그에 따른 ADR |
| 3. 첫 루프 | 스파이크 결과로 음성 경로와 기기 제어 구현 | 가족이 1주 동안 매일 사용하고 실패율을 잴 수 있다 |
| 4. 확장 | 휴대폰 앱, 대시보드, 방송 | 첫 루프 1주 사용 결과로 범위 재조정 |

작업 방식: 구현은 Sonnet 서브에이전트가 별도 브랜치(worktree)에서 하고, Claude가 diff를 검토한 뒤 PR로
main에 fast-forward 병합한다. 설계·ADR·계획 같은 판단 문서는 Claude가 작성한다.
